# 🔐 Анализ сетевого трафика — раскрытие приватного ключа и расшифровка TLS

## 📌 Описание

В данном репозитории представлен полный анализ сетевого дампа `cap3.pcapng`, выполненный в рамках задания по направлению «Информационная безопасность».

В результате анализа продемонстрирована полная расшифровка TLS-сессии вследствие раскрытия приватного ключа и отсутствия Perfect Forward Secrecy.

---

## 🔎 Основные находки

- Приватный RSA-ключ доступен по HTTP-ресурсу `/k3y`
- TLS-сервис работает на порту 1338
- Используется шифр `TLS_RSA_WITH_AES_256_CBC_SHA`
- Отсутствует Perfect Forward Secrecy (PFS)
- Используется устаревший протокол TLS 1.0
- TLS-сессия успешно расшифрована
- Извлечён защищённый ресурс `/file`

---

## 💣 Результат

Комбинация утечки приватного ключа и небезопасной криптографической конфигурации позволила выполнить полную расшифровку TLS-сессии и извлечь передаваемые данные.
